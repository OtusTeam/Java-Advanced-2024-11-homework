## Описание
Этот проект демонстрирует реализацию модульного приложения на базе Spring Boot. Архитектура приложения включает 4 основных модуля:

- **api** — верхнеуровневый модуль, предоставляющий REST API для взаимодействия с приложением.
- **service** — модуль, отвечающий за сохранение данных.
- **provider** — модуль, имитирующий получение данных из внешнего источника.
- **core** — модуль, содержащий реализацию базы данных (на основе HashMap).

## Функциональность
Приложение предоставляет REST API для работы с данными:
- **GET /save** — сохранить данные.
- **GET /all** — получить все сохранённые данные.
