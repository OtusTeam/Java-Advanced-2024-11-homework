# Кэш с использованием WeakReference и SoftReference

## Описание

Данное приложение реализует абстрактную структуру данных типа кэш с двумя реализациями: на основе `WeakReference` и `SoftReference`. Программа позволяет кэшировать содержимое текстовых файлов из указанной директории и быстро получать доступ к ним.

## Функциональность

- Указание кэшируемой директории
- Загрузка содержимого файлов в кэш
- Получение содержимого файлов из кэша
- Возможность выбора типа кэша (Weak Reference или Soft Reference)

## Архитектура

Проект имеет следующую архитектуру:
- `Cache<K, V>` - интерфейс, определяющий основные операции кэша
- `AbstractCache<K, V>` - абстрактный класс, реализующий базовую логику кэша
- `WeakReferenceCache` - реализация кэша с использованием WeakReference
- `SoftReferenceCache` - реализация кэша с использованием SoftReference
- `CacheFactory` - фабрика для создания экземпляров кэша
- `Emulator` - класс для взаимодействия с пользователем

## Технологии

- Java 21
- JUnit 5 для тестирования

## Запуск

Для запуска приложения выполните:

```bash
mvn compile exec:java -Dexec.mainClass="dev.korolz.cache.menu.Emulator"
```

в папке проекта.

## Использование

1. При запуске выберите тип кэша (Weak Reference или Soft Reference)
2. Используйте меню для:
    - Указания кэшируемой директории
    - Загрузки содержимого файла в кэш
    - Получения содержимого файла из кэша

## Различия между WeakReference и SoftReference

- **WeakReference**: объекты, на которые ссылаются только слабые ссылки, могут быть удалены сборщиком мусора при следующем цикле сборки мусора
- **SoftReference**: объекты, на которые ссылаются программно-ориентированные ссылки, удаляются только перед возникновением OutOfMemoryError
