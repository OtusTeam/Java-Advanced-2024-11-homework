# Тестирование нагрузки сервиса регистрации пользователей

## Описание проекта
Тестовый план для проверки производительности REST API регистрации пользователей 
с возможностью регулировки RPS (Requests Per Second).

## Технологии
- **JMeter 5.6.3**
- Java 17
- Spring Boot (для тестируемого приложения)
- H2 Database

## Тестируемое приложение
- `User` (`id`, `login`, `password`, `largeData`)
- `UserRepository` (JpaRepository для H2)
- `UserService` (логика регистрации + кэширование)
- `UserController` (REST API: `POST /api/register`)

## Настройки Теста (Thread Group)
| Параметр              | Значение  | Описание                          |
|-----------------------|----------|-----------------------------------|
| Количество потоков    | 10       | Число виртуальных пользователей   |
| Ramp-up период        | 1 сек    | Время наращивания нагрузки        |
| Число повторов        | 10       | Итераций на каждый поток          |
| Общее кол-во запросов | 100      | (10 потоков × 10 итераций)        |

## Параметры HTTP-запроса
```json
{
  "login": "случайный UUID",
  "password": "случайная строка 8 символов"
}
```


### Результаты тестирования
#### Сводная статистика
```text
summary = 100 in 00:00:01 = 102.0/s Avg: 9 Min: 5 Max: 131 Err: 0 (0.00%)
```


#### Ключевые метрики:

| Метрика               | Значение | Описание              |
|-----------------------|----------|-----------------------|
| Общее кол-во запросов | 100      | Все запросы выполнены |
| Время выполнения      | 1 сек    |                       |
| Throughput (RPS)      | 102      | запроса в секунду     |
| Среднее время отклика | 9 мс     |                       |
| Минимальное время     | 5 мс     |                       |
| Максимальное время    | 131 мс   | Пиковая задержка      |
| Ошибки                | 0%       | Все запросы успешны   |


#### Анализ производительности

- Пропускная способность: 102 RPS - сервис выдерживает высокую нагрузку
- Стабильность: Разброс времени отклика от 5 до 131 мс указывает на:
- - Быструю обработку простых запросов
- - Возможные задержки при конкуренции за ресурсы
- Надежность: 0% ошибок - сервис стабилен при текущей нагрузке


## Тестирование

### Сборка приложения
```bash
mvn clean install
```

### Запуск основного приложения
```bash
cd app
mvn spring-boot:run
```

### Запуск кода тестов Jmeter


```bash
cd jmeter-load-test
mvn exec:java
```


*Внимание!* Для корректной работы нагрузочных тестов, реализованных на Java
с использованием Apache JMeter, требуется наличие установленного
Apache JMeter версии 5.6.3.
Дистрибутив должен быть размещён в файловой системе,
а его расположение задано в переменной окружения JMETER_HOME.

Использование переменной в коде:
```java
var jmeterHome = System.getenv("JMETER_HOME");
```
