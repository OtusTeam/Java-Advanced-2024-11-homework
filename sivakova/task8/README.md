# Нагрузочное тестирование сервиса регистрации пользователей

Данный проект включает в себя два подпроекта:

- `auth-service` — Spring Boot REST-сервис регистрации пользователей.
- `jmeter-test` — нагрузочный тест для проверки регистрации пользователей через API `auth-service`, создаётся и запускается с помощью JMeter через Java API.

## Структура проекта
```
.
├── auth-service/ # REST API для регистрации пользователей
├── jmeter-test/ # Java-программа, создающая и запускающая нагрузочный тест в JMeter
    ├── auth_service_generated_test_plan.jmx/ # Тестовый план, сгенерированный во время запуска нагрузочного теста в `jmeter-test`
    ├── logs.jtl/ # логи выполнения теста в `jmeter-test`
├── auth_service_test_plan.jmx/ # Тестовый план, созданные через UI-интерфейс JMeter'а
└── README.md
```
## Сборка проекта
В корне проекта выполните:
```
mvn clean install
```

## Запуск сервиса регистрации пользователей `auth-service`

Перейдите в директорию `auth-service` и выполните:

```
mvn spring-boot:run
```

## Нагрузочный тест `jmeter-test` сервиса регистрации пользователей

Использует 100 параллельных потоков (виртуальных пользователей).

Продолжительность теста — 60 секунд.

Принимает RPS (запросов в секунду) как обязательный параметр командной строки.

### Запуск нагрузочного теста:

1. Убедитесь, что переменная окружения JMETER_HOME установлена.
2. Запустите тест с указанием желаемого RPS (запросов в секунду), например 100:
```
java -jar target/jmeter-test-0.0.1-SNAPSHOT-shaded.jar 100
```
