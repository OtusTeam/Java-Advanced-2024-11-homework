# Реактивный сервис регистрации пользователей (Spring WebFlux)

Приложение реализует реактивный сервис регистрации и работы с пользователями на основе **Spring WebFlux** и **Reactive MongoDB**, с использованием встроенной базы данных MongoDB через Flapdoodle.

---

##  Возможности

- Регистрация пользователей
- Получение списка всех пользователей
- Получение списка всех имен пользователей (в формате JSON-массива)
- Получение списка email'ов только с непустыми значениями
- Полностью реактивная архитектура (`Mono`, `Flux`)
---

## Архитектура

- `UserController` — REST API
- `UserServiceImpl` — бизнес-логика
- `UserRepository` — `ReactiveMongoRepository`
---

```bash
mvn clean spring-boot:run
```
