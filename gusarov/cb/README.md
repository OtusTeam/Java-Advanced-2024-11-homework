# CircuitBreaker 

### Описание:
* Swagger: http://127.0.0.1:8098/swagger-ui/index.html
* Добавлен метод (POST) http://localhost:8098/api/v1/users которому в теле передаётся login и password
* Логин уникальный, длина логина и пароля ограничена 100 символами.
* Добавлен метод получения возраста пользователя по ид. (http://localhost:8098/api/v1/users/a67ecd06-7f62-4f4c-8620-b4133bbf7344/year)
* Созданы 3 jmx (20rps, 21rps, и 1rps) для проверки.
