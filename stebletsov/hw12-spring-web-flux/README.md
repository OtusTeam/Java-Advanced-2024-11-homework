# Домашнее задание №12

## Реализация реактивного сервиса

## Цель: Переписать сервис регистрации в реактивном стиле с использованием Reactor или Spring Web Flux

## Описание/Пошаговая инструкция выполнения домашнего задания:

Переписать сервис регистрации в реактивном стиле с использованием Reactor или Spring Web Flux

- Контроллеры должны возвращать Publisher'ы
- Сервисы должны возвращать Publisher'ы
- Репозитории должны возвращать Publisher'ы
- Добавить в контроллер методы:
  - Возвращающий список пользователей
  - Возвращающий список всех имен пользователей, массивом JSON
  - Возвращающий список email'ов, но только заполненных
